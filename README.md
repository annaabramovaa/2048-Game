# 2048 Game 
A classic 2048 puzzle game built with vanilla JavaScript, HTML, and SCSS. Players slide numbered tiles across a 4×4 grid, combining tiles with the same value to create higher numbers. The goal is to reach the 2048 tile while aiming for the highest possible score.
## Technologies Used
This project was built using the following technologies:
- **HTML5:** Used to structure the page content with semantic and accessible markup.
- **SCSS** — styling
- **JavaScript:** Used to implement interactive elements and dynamic functionality with modern JavaScript features.
- **Node.js:** Used as the JavaScript runtime environment for the project.
- **NPM:** Used to manage dependencies and project scripts.
- **Parcel:** A fast, zero-configuration bundler used to build and optimize the project.
- **Git:** Used for version control and tracking changes throughout development.
- **GitHub:** Used to host the repository and manage the project code.
## Features 
- **Classic 2048 Gameplay**: Combine matching tiles to create higher values and reach the 2048 tile.
- **Score Tracking**: The current score is updated in real time as tiles are merged.
- **Keyboard Controls**: Move the tiles using the arrow keys for smooth gameplay.
- **Game States**: Includes dedicated start, win, and game-over states with clear feedback.
- **Restart Anytime**: Start a new game at any time without refreshing the page.
- **Responsive Board**: A clean 4×4 game board that adapts to different screen sizes.

To run this project, you will need:

- **Node.js** (version 14.x or newer): A JavaScript runtime built on Chrome's V8 JavaScript engine, used for server-side scripting.
- **NPM** (version 6.x or newer): The Node.js package manager, used for managing project dependencies.

## Installation and Setup

To install the project and run it locally, follow these steps:

1. Clone the repository:

    ```
    git clone https://annaabramovaa.github.io/2048-Game/
    ```

2. Navigate to the project directory:

    ```
    cd 2048-Game
    ```

3. Install dependencies:

    ```
    npm install
    ```

4. Start the local development server:

    ```
    npm start
    ```
5. Open http://localhost:8080/ in your browser to view the website.
